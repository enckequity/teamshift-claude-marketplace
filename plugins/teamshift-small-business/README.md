# TeamShift small business

Three skills that help a small-business owner with routine writing work.

- **quote-followup** drafts a follow-up message for a quote that has gone quiet.
- **review-reply** drafts a reply to a customer review, positive or negative.
- **sop-from-recording** turns a narrated walkthrough of a task into a written standard operating procedure.

## Use

Install the plugin from the TeamShift marketplace, then ask Claude for the task in plain words, for example "follow up on the Miller quote" or "write a reply to this review". Each skill asks for anything it needs, such as the quote details or the review text.

## Data and setup

The skills run inside your Claude session. They contain no servers, hooks or scripts, send nothing to any other service and need no setup. Drafts are text for you to review before you send anything.

Each skill has a sample case under `evals/` that checks its output.
